### 大屏体验，不止是把画面放大

- **车机只需浏览器。** 特斯拉使用固定地址，也可以让电脑、平板等同一局域网设备访问手机显示的地址。
- **安卓投屏拥有独立画面。** 目标应用运行在虚拟显示屏，不必一直占着手机主屏幕；兼容应用支持浏览器触控回传。
- **无线与有线，入口分明。** CarPlay 页面用于无线连接，USB 页面负责有线接收，不必为无线模式检查 iPhone 数据线。
- **USB 优先高清直传。** 浏览器支持时直接播放 iPhone 的 H.264/H.265 视频，避免 JPEG 二次压缩；不兼容时自动回退 MJPEG，也可手动选择兼容模式。
- **为不同大屏选择合适比例。** USB 提供 Tesla 5:4、16:9 与 1:1 三种配置，停止接收后即可切换，浏览器保持等比显示。
- **连接过程看得见。** USB 页面显示认证、连接、视频与浏览器状态，支持复制脱敏日志，排查时不用只面对一块黑屏。

高清、音频和触控效果取决于手机、发送设备、网络及浏览器能力，不能保证所有车型或设备完全一致。

## 第一次使用，先准备这些

你需要一部 Android 10 及以上手机，以及能访问手机网络地址的车机或其他设备浏览器。**iPhone 不能单独运行这款 Android App**；使用 CarPlay 或 AirPlay 时，它是连接到安卓接收端的发送设备。

| 模式 | 额外准备 | 是否需要 Stellar / Shizuku |
|---|---|---|
| 安卓应用投屏 | 手机已安装并初始化目标应用 | 需要 |
| 无线 CarPlay 浏览器 | 有效认证、iPhone 蓝牙配对、无线网络／热点配置 | 需要，当前浏览器路径使用虚拟屏 |
| 独立 USB CarPlay | 有权使用的本地认证文件、USB OTG 数据线、USB 与 VPN 授权 | 不需要 |
| AirPlay 镜像 | 支持 AirPlay 的 iPhone、iPad 或 Mac，以及可互通网络 | 不需要 |

**两种网络方式：**

| 方式 | 怎样连接 | 浏览器地址 |
|---|---|---|
| Tesla 固定地址 | 让车机连接安卓手机热点，按 App 提示准备网络并授权 VPN | 普通投屏通常为 `http://99.99.99.99:8080`；USB 为 `http://99.99.99.99:8088` |
| 局域网 | 手机、发送设备和浏览器设备连接可互通的同一网络 | 使用 App 显示的手机 IP 与端口 |

**固定地址就绪不代表热点已经打开。** 请确认热点实际开启、车机已连接。普通投屏端口被占用时会使用备用端口，始终以 App 显示的完整地址为准；USB 固定使用 `8088`。

## 使用方法

### 1. 安卓地图 / 应用投屏：把熟悉的操作带到大屏

1. 在安卓手机安装要投屏的应用，至少打开一次，完成初始化与必要授权。
2. 安装 [Stellar](https://github.com/roro2239/Stellar/releases) 或 [Shizuku](https://shizuku.rikka.app/download/)，按工具提示配对、启动服务。在特投屏 **准备** 页完成特权授权；页面提供 Stellar 首次配置引导。
3. 打开 **投屏**，点击六个自定义位置添加应用，再选择目标以及 Tesla 或局域网模式。六个位置均可更换或清除，原先的固定地图应用也可自行添加；升级保留已有自定义配置。浏览器 Dock 折叠后，展开按钮位于左下角。
4. 点击 **免费开始投屏**，在车机浏览器打开 App 显示的地址。
5. 画面出现后，通过浏览器点击、拖动与返回操作目标应用。

Android 11 及以上通常可使用无线调试配对；Android 10 的 Shizuku 通常需要电脑 ADB 启动。手机重启或特权服务被系统停止后，需要重新启动该服务。

不同应用对虚拟屏的支持程度不同；应用已安装，不等于一定可以正常投屏。

### 2. 无线 CarPlay：不用 iPhone 数据线，也能连接大屏

1. 在手机打开 **CarPlay** 设置，完成定位、蓝牙、附近设备、麦克风等所需授权。
2. 配置有效认证。选择本地认证时，在宿主设置中点击 **Import key and certificate**，依次导入有权使用的 `identity.pk8` 与匹配的 `certificate.p7b`。
3. 在安卓蓝牙设置中与 iPhone 配对；必要时在宿主 **Paired iPhone (Bluetooth)** 中明确选择该设备。
4. Tesla 模式在宿主设置中选择 **MANUAL** 热点，填写与安卓手机热点一致的 SSID、密码和安全类型，并让车机连接该热点。局域网模式可按宿主设置选择相应无线网络方式。
5. 完成准备页的 Stellar/Shizuku 授权，回到 **CarPlay** 免费启动，在车机浏览器打开 App 显示的地址。

**无线 CarPlay 不要求插入 iPhone USB 数据线。** 蓝牙配对完成、本地文件校验通过，都不等于 CarPlay 会话已经连接；请以实际会话与画面状态为准。

### 3. USB CarPlay：一根数据线，独立的浏览器接收入口

1. 先在手机 CarPlay 设置中导入有权使用的本地 MFi 私钥与匹配证书。
2. 打开 **USB**，选择画面比例：**Tesla 5:4（1120×896）**、**16:9（1280×720）** 或 **1:1（1024×1024）**。
3. 使用支持数据传输的 USB OTG 连接方式接入 iPhone，点击 **连接 USB iPhone 并启动浏览器**，按提示允许 USB 访问与 VPN 授权。
4. 浏览器打开 `http://手机IP:8088`；Tesla 模式打开 `http://99.99.99.99:8088`。**直接输入 IP 和端口，无需 token。** Tesla 模式仍需确认手机热点已开启、车机已连接。
5. 默认声音由手机播放。想让浏览器播放，点击网页 **开启声音**；点击 **手机播放** 或关闭网页可恢复手机输出。
6. 若浏览器不支持高清解码，使用自动回退或手动 **兼容模式**。遇到问题，查看 App 的连接日志或网页 **日志**。

USB 接收不需要 Stellar/Shizuku，也不会创建安卓虚拟显示屏。它与普通无线 CarPlay 浏览器路径是不同模式。

H.264/H.265 直传通过浏览器 MSE 播放；安全上下文且支持时优先使用 WebCodecs。浏览器不支持对应编码时保留 MJPEG。真实 iPhone、USB 供电／枚举及 Tesla 浏览器兼容性需要对应设备验证。

### 4. AirPlay：让 iPhone、iPad、Mac 的画面也能上大屏

1. Tesla 模式让发送设备和车机连接安卓手机热点；局域网模式让三者连接同一可互通网络。
2. 打开 **AirPlay**，按提示开启接收与浏览器入口，首次使用固定地址时允许 VPN 授权。
3. 先在车机浏览器打开 App 显示的地址，网页会等待发送设备连接。
4. 在 iPhone、iPad 或 Mac 控制中心打开 **屏幕镜像**，选择 **特投屏 AirPlay**。
5. 连接后画面自动显示；浏览器提示声音可用时，点击 **开启声音**。

竖屏内容保持原比例，可能保留黑边；横屏内容能更充分地利用大屏。AirPlay 不支持浏览器反控 iPhone，也不保证能显示受 DRM 保护的流媒体内容。

发送设备断开后接收入口保持运行，再次连接可恢复。接收与浏览器播放均永久免费、不限时，不再记录每日试用额度。

## 常见问题

### 手机可以熄屏或锁屏吗？

投屏服务设计为在后台运行，不需要一直点亮安卓手机屏幕。地图投屏（含无线 CarPlay 浏览器）、AirPlay 与 USB 接收使用前台服务和 CPU 部分唤醒锁；锁屏不会主动停止服务。

此前 Android 测试手机上，地图投屏在熄屏 35 秒后仍持续输出新帧。**这不是所有手机的长期锁屏保证**：厂商省电、后台清理、热点自动关闭或特权服务退出仍可能中断连接；无线／USB CarPlay 与 AirPlay 的真实发送设备锁屏回归仍需硬件验证。请允许后台运行，保持网络连接，勿强制停止服务。5.0 不设任何每日投屏时长限制。

### 为什么打开地址却没有画面？

先确认浏览器已连到正确的手机热点或局域网，地址和端口与 App 一致，再看 App 是否已收到发送设备的视频。USB 可查看认证与连接日志，并尝试兼容模式。公共 Wi-Fi 的设备隔离、热点自动关闭、USB 线不支持数据，都可能导致连接失败。

### 需要会员或赞助才能使用全部功能吗？

**不需要。所有功能永久免费、不限时。** 升级后不再读取会员权益、本地解锁状态或已用完的每日额度，也不依赖赞助服务器来允许投屏。赞助纯属自愿；CarPlay 认证材料、系统授权和网络配置仍由用户准备。

### 证书、私钥在哪里获取？安装包里有吗？

正式安装包和未启用本机身份注入的普通 debug 包都不包含认证证书或私钥。用户需自行准备有权使用的身份或认证设备／服务。导入只验证文件格式及密钥匹配，不能保证 iPhone 信任该身份。请勿公开或转发私钥。

### 可以同时开启几种投屏吗？

不同模式会竞争 USB、VPN、端口及媒体资源，App 在切换相关页面时会停止冲突服务。建议一次只使用一种投屏模式。USB 在转到准备或赞助页时可继续运行，停止接收请使用 USB 页的停止按钮。

### 最新版可以直接覆盖安装吗？

同包名、同签名且版本号更高的正式 APK 可直接覆盖更新，通常无需卸载。请以实际 Releases 中提供的安装包为准；卸载可能清除设置及已导入的本地身份。
