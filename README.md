Navipilot 是一款 Android 车机导航辅助 App，核心能力是把手机上的车机版地图投屏到同一局域网内的浏览器，例如特斯拉车机浏览器、平板浏览器或电脑浏览器。用户可以在手机端选择高德车机版、腾讯车机版或百度车机版，App 会在手机本地创建一个虚拟屏幕运行地图，再把画面通过 HTTP 推送到浏览器，并支持浏览器触摸反控。

除了投屏，Navipilot 也可以连接 comma3 / openpilot 设备，把导航数据、车辆状态、车道线识别结果和红绿灯辅助信息联动起来，用于驾驶辅助场景。

> **安全说明**：本项目提供导航显示、投屏、设备状态展示和驾驶辅助信息，不替代驾驶员观察、判断或车辆原有安全系统。驾驶员必须始终注意道路并对车辆控制负责。

## 主要功能

| 功能 | 说明 |
|---|---|
| 地图投屏到车机浏览器 | 将手机中的高德车机版、腾讯车机版或百度车机版投屏到浏览器，适合特斯拉等支持车机浏览器的车型。 |
| 浏览器触摸反控 | 浏览器中的点击、拖动、返回等操作会回传到手机虚拟屏，实现远程操作地图。 |
| 自适应画面尺寸 | 浏览器连接后会上报可视区域，App 根据浏览器窗口动态调整虚拟屏分辨率。 |
| 局域网 HTTP 服务 | 手机本地启动投屏服务，默认监听 `8080`，被占用时自动尝试 `8081` 到 `8099`。 |
| 试用与会员 | 未开通时可直接点击“试用”启动 18 分钟投屏；会员用户点击“投屏”可不限时使用。 |
| 高德车机版回家 / 公司快捷导航 | 选择高德车机版时，可通过首页滑动条调用高德车机版已设置的家和公司地址。 |
| comma3 连接 | 可发现并连接 comma3，显示车辆状态、驾驶 HUD、车道线和红绿灯辅助卡片。 |
| 导航数据发送到 comma3 | 将高德车机版导航广播转换为 comma3 可用的 UDP 7706 导航数据。 |
| 本地车道线识别 | 使用本地 `lane.onnx` 模型识别道路相机画面中的实线 / 虚线，并回传 comma3。 |

## 投屏适合哪些场景

- 特斯拉车机浏览器打开手机投屏地址，用车机屏幕查看手机地图。
- 车内平板、电脑或另一台手机通过浏览器查看并操作导航地图。
- 需要在车机大屏使用高德车机版、腾讯车机版、百度车机版，但车辆系统本身无法安装这些 App。
- 希望导航投屏和 comma3 / openpilot 辅助信息共存，但两者也可以独立使用。

## 投屏工作原理

Navipilot 的投屏不是简单录制手机主屏幕，而是在手机内部创建一个独立的虚拟 Display。目标地图 App 会运行在这个虚拟屏上，因此投屏画面不会遮挡手机主界面，用户仍然可以在 Navipilot 首页查看状态和控制投屏。

```text
目标车机地图 App
  -> 特权虚拟 Display
  -> ImageReader 捕获画面
  -> JPEG / MJPEG 编码
  -> 手机本地 HTTP 服务 /stream
  -> 车机或其他设备浏览器显示

浏览器触摸 / 返回事件
  -> WebSocket /control
  -> ProjectionService
  -> 特权服务注入到虚拟 Display
  -> 地图 App 响应操作
```

### 1. 虚拟屏运行地图

App 通过 Shizuku 或 Stellar 授权启动特权服务，由特权服务创建虚拟 Display，并把高德车机版、腾讯车机版或百度车机版启动到该 Display 上。这样可以让地图在后台专用画布中运行，而不是占用手机当前屏幕。

### 2. 画面采集与编码

虚拟屏画面由 `ImageReader` 获取，编码后写入最新帧缓存。浏览器访问 `/stream` 时，App 持续输出 MJPEG 视频流。投屏页面右上角只显示简化后的帧率信息，方便判断当前画面是否流畅。

### 3. 浏览器反控

浏览器页面会监听 Pointer Events，把点击、拖动、抬手等事件转换为归一化坐标，通过 `/control` WebSocket 发回手机。手机端再把这些事件注入到虚拟 Display，目标地图 App 就会像被本地触摸一样响应。

### 4. 自适应浏览器窗口

浏览器打开页面后会回报窗口宽高、设备像素比和方向信息。App 根据这些信息调整虚拟屏参数，让投屏画面尽量贴合车机浏览器或横屏设备。

## 投屏使用步骤

1. 在手机上安装高德车机版、腾讯车机版或百度车机版。
2. 在手机实体屏幕上先打开一次目标地图，完成首次引导和定位权限授权。
3. 安装并启动 Shizuku 或 Stellar，完成授权。
4. 打开 Navipilot，在“地图导航投屏”区域选择目标地图和连接方式。
5. 未开通会员时点击“试用”，会员用户点击“投屏”。
6. 在车机浏览器或同一局域网设备浏览器中打开 App 显示的地址，例如 `http://192.168.31.92:8080/`。
7. 浏览器出现地图画面后，即可在浏览器上触摸操作地图。

如果 `8080` 打不开，可能是端口被占用或网络不可达。App 会自动尝试 `8081` 到 `8099`，请以 App 页面显示的最新地址为准，并确认手机和浏览器设备在同一局域网内。

## 试用与会员逻辑

- 未开通会员时，首页主按钮显示“试用”，点击后直接启动 18 分钟投屏。
- 试用到时后，投屏会自动停止，并弹出会员页面。
- 会员用户首页主按钮显示“投屏”，点击后启动不限时投屏。
- 用户也可以随时点击“会员”按钮进入购买、恢复或设备迁移页面。
- 浏览器投屏成功后，底部推广信息只在试用状态显示；会员投屏不显示底部广告。

## 高德车机版回家 / 公司快捷导航

当投屏目标选择为高德车机版时，首页会显示“回家 / 导航 / 公司”滑动条。向左或向右滑动到阈值后，App 会调用高德车机版的一键导航广播：

```text
Action: AUTONAVI_STANDARD_BROADCAST_RECV
KEY_TYPE: 10040
DEST: 0 表示回家，1 表示公司
IS_START_NAVI: 0
```

这个功能依赖高德车机版自身保存的家和公司地址。Navipilot 不会保存或猜测用户地址，如果高德车机版未配置对应地址，应先在高德车机版中设置。

## comma3 / openpilot 连接能力

投屏功能可以独立使用，不要求连接 comma3。连接 comma3 后，Navipilot 会额外提供以下能力：

| 能力 | 说明 |
|---|---|
| 设备发现与连接 | 在局域网内发现 comma3，并连接 carrot server。 |
| 驾驶 HUD | 显示车速、限速、道路名称、转向、剩余里程等信息。 |
| 导航数据桥接 | 接收高德车机版广播，转换为 comma3 使用的导航 JSON，通过 UDP 7706 发送。 |
| 路线顶点发送 | 路线规划完成后，通过 TCP 7709 发送路线点。 |
| 实时车辆状态 | 通过 WebSocket 读取 `carState`、`modelV2`、`controlsState`、`deviceState` 等数据。 |
| 车道线识别 | 从 comma3 道路相机快照中本地识别左右车道线实线 / 虚线并回传。 |
| 红绿灯辅助 | 显示信号灯、方向、倒计时和停车线距离等辅助信息。 |

连接成功后，首页会自动隐藏“使用提示”卡片，并显示驾驶 HUD、车道线和红绿灯辅助卡片。未连接 comma3 时，这些辅助卡片会自动隐藏，避免页面显示无效信息。

## comma3 数据链路原理

```text
高德车机版导航广播
  -> AmapBroadcastManager
  -> AmapBroadcastHandlers
  -> CarrotManFields
  -> NetworkManager
  -> UDP 7706 / TCP 7709
  -> comma3 / carrot server
```

`CarrotManFields` 是 App 内导航数据的共享状态。`CarrotManNetworkClient.build7706Payload` 是 UDP 7706 的序列化契约，负责输出目的地、手机 GPS、导航 GPS、限速、电子眼、TBT 转向、剩余里程和命令字段等数据。

高德、腾讯等国内地图通常使用 GCJ-02 坐标，comma3 / openpilot 侧使用 WGS-84。App 在地图边界通过 `CoordinateConverter` 完成坐标转换，内部发往 comma3 的坐标保持 WGS-84。

## 本地车道线识别原理

车道线识别使用仓库中的 `app\src\main\assets\lane.onnx` 模型，在手机本地通过 ONNX Runtime 执行推理，不上传道路图像。

```text
comma3 roadgray.jpg
  -> LaneDetectionManager
  -> LaneInferenceEngine
  -> 左右相邻线：实线 / 虚线 / 不可用
  -> UDP 4213
  -> comma3
```

当网络或推理失败时，App 不会伪造车道线结果，设备侧可通过超时机制自然淘汰旧数据。

## 隐私与安全

- 投屏画面和触摸事件默认只在用户局域网内传输。
- 车道线模型在手机本地推理，不上传道路相机画面。
- `local.properties`、签名密码、支付密钥、API Key、设备令牌等敏感配置不应提交到仓库。
- 车机浏览器访问投屏地址时，请确保连接的是可信局域网，避免在公共网络中暴露投屏服务。

本仓库未在根目录声明统一开源许可证。复用、分发或商用前，请确认仓库维护者以及地图 SDK、模型和第三方组件各自的许可条款。
